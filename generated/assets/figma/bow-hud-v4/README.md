These SVGs are original Melodia UI atoms promoted for a bounded cozy website polish.
They are decorative only: no baked text, no gameplay values, no third-party reference art.

Website usage is scoped by `wix/melodia-cozy-bow.css` and freeze exception
`bow-hud-cozy-website-polish-2026-10-02`.

The homepage uses only light storybook/chrome cues. The Melusina page may show the
orrery/artifact vocabulary more explicitly. Reduced-motion and coarse-pointer states
remain quiet and readable.
