# Recruiter-facing truth + voice audit — 2026-09-18

## Rule

The public site is an art portfolio, not an agent status dump.

Every factual claim must fall into one of three buckets:

- **shown** — visible directly on the page or in a linked capture;
- **verified** — backed by current project evidence;
- **study / in progress** — interesting, but not presented as shipped production fact.

If a number, protocol, tool version, asset count, performance claim, or production-status label cannot be verified quickly, remove the precision before publishing it.

## Voice

Write like Brennan talking about his own work:
- first person where authorship matters;
- concrete nouns and verbs;
- art first, machinery second;
- short enough to read while looking at images;
- a little strange / musical / playful is good;
- no fake-enterprise language.

Avoid:
- "enterprise architecture", "multi-modal infrastructure", "innovations", "production-ready" without evidence;
- inflated words such as "seamlessly", "revolutionary", "advanced", "robust";
- unexplained exact counts generated by old agents;
- descriptions that read like a model inferred the project from filenames;
- calling experiments "live", "automated", or "integrated" unless current evidence proves it.
