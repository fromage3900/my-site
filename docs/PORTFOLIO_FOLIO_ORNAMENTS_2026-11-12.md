# Folio ornament toolkit — November 12, 2026

The visual concept uses ribbon sweeps, ornate corner brackets and a star/crescent insignia. These were not provided as usable web assets in the generated mockup.

This commit adds lightweight, original, static SVG counterparts with no added JavaScript:
- `wix/assets/editorial/folio-corner.svg` — reusable artwork corner, rotated to four corners.
- `wix/assets/editorial/rose-ribbon.svg` — soft translucent silk-fold sweep below the main fold, scaled down on mobile.
- `wix/assets/editorial/celestial-seal.svg` — moon-and-star vector seal used in header and divider.

The dark plum editorial page remains art-led. All ornament elements are purely decorative, hidden from screen readers and pointer-transparent. The sources can be replaced later with the artist's own hand-drawn motifs, but hand drawing is **not required** to deploy the design.

Do not use generative concept images as actual render screenshots. Keep the source Unreal artwork and technical evidence intact.
