The Stack

Full toolchain.

Every tool in the pipeline, with its role in the production flow.

Unreal Engine 5.8

Environment assembly, Substrate Toon materials, PCG scattering, post-process toon outlines, and Python capture pipeline for renders.

Blender 5.1

Stylized geometry, modular kit construction, surreal_arch procedural generation engine (42 style genomes), and FBX export to UE.

Material Maker

Procedural PBR graph authoring. v1: 72 nodes, 5 export maps. v2 redesign: 3-layer, ~105 nodes, 8 export maps, separate diffuse/specular channels.

Substance 3D Painter

PBR texture baking, hand-painted wear/dirt masks, material reference for toon color ramps and ornamental detail.

TouchDesigner

Real-time VFX prototyping. MCP server via Embody/Envoy for AI-assisted TD network creation and operator editing.

VS Code + PowerShell

Website source editing, deploy automation (sync_site_to_github.ps1), render ingestion (ingest-renders.ps1), and environment scaffolding (add-environment.ps1).

GitHub Pages

Static hosting via git worktree on main branch. Wix iframe embeds the portfolio at full viewport. Zero-cost, version-controlled, one-command publish.

Production Flow

World → website in 7 steps.

Each environment follows the same pipeline from first mesh to live page.

01
Model environment in Blender — modular kit, style genome, or hand-sculpted.
02
Export FBX assets to UE5 EnvSandbox. Assign Substrate Toon materials from master library.
03
Build PCG graphs — scatter, spline routes, density falloff, biome blending.
04
Capture hero stills, establishing shots, material isolates, and webm loops via Python pipeline.
05
Run .\tools\ingest-renders.ps1 — copies new captures into wix/generated/assets/
06
Create or update the environment page — use .\tools\add-environment.ps1 for new worlds.
07
Run .\deploy\quick-deploy.ps1 — syncs to worktree, commits, pushes. Live in ~30 seconds.
