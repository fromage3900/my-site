Echo Pipeline Core Systems

Subsystem Architecture & Innovations

Modular automation engines powering real-time rendering, material math, CHOP audio reactivity, and web compiler outputs.

UE 5.8 C++ & Blueprint Socket API

Unreal Engine 5.8 C++ core backed by Monolith MCP (Port 9316) logging telemetry to Saved/Logs/MonolithCalls.jsonl. Operates UEBlueprintMCP socket interface (Port 55558 TCP) enabling dynamic length-prefixed graph node query and injection without manual editor intervention.

Blender 5.2 Melodia Studio & BlenderMCP

Melodia Studio (operators surreal_arch.* / mel_gn.*): 165 GN builders, 12 GN Stack categories. Agent control is BlenderMCP :9876 (N → BlenderMCP → Connect). Live Bridge LiveLink is a stub. Mocap clips retarget through RTG_Mocap_to_Melusina onto SK_Melusina_Skeleton — they do not import directly onto the skeleton. Port 9317 is legacy.

Automated Material Crosswalks & Toon Math

Converts sRGB color space to Linear via standard transformation:
Linear(c) = c / 12.92 for c ≤ 0.04045, else ((c + 0.055) / 1.055)^2.4.
Hex #352D40 Warm-Violet Evaluation: R=53 (0.20784 → Linear 0.035133), G=45 (0.17647 → Linear 0.026330), B=64 (0.25098 → Linear 0.052814). Evaluated Vector: LinearColor(0.035133, 0.026330, 0.052814, 1.0).
Script create_tp_melusina.py generates TP_Melusina configuring DiffuseRamp, SpecularRamp, indirect intensity (0.3), extinction (0.3), and T_HatchPattern.

TouchDesigner 4-Band RMS Audio Streamer

Script build_harmonic_audio_streamer.py constructs real-time CHOP audio analysis pipeline:
1. Sub-Bass (20–100Hz): Triggers camera shake & low-frequency Niagara ground pulses.
2. Mid-Range (250–2500Hz): Modulates vocal/instrumental lighting & rim light brightness.
3. High-Frequency (4k–12kHz): Drives particle sparkle emitters & rhythm highway highlights.
4. Master RMS Envelope: Controls global atmospheric pulse & post-process bloom.

VOICEVOX & Melusina Neural Speech

Dual REST speech synthesis pipeline leveraging VOICEVOX (Port 50021 REST) with 7 Japanese character voice models, alongside the Melusina custom voice proxy (Port 50022 REST) for automated dialogue audio generation and lip-sync metadata generation.

Web Asset Product Compiler

Script tools/build_asset_products.py compiles raw 3D renders into web-ready distribution packages:
• 135 Twitch Emotes: 15 types × 3 resolutions (28x28, 56x56, 112x112) × 3 background modes.
• 7 OBS Overlays: 1080p stream templates + UI frames.
• 78 Phone Wallpapers: Across 3 screen aspect ratios.
• 12 Postcards: 300dpi print-ready front designs + 1 canonical back template.

Git LFS & Live-Ops Infrastructure

Enterprise live-ops architecture enforcing mandatory Git LFS asset locking (lockable attribute across .uasset, .umap, .blend, .fbx). Integrates runtime feature flags via UMelodiaFeatureFlagSubsystem and a 6-week trunk-based release workflow.

Production Flow

Echo Multi-Modal 7-Stage DCC Data Pipeline

Data execution pathway from Blender 5.2 asset authoring to web product compilation and live-ops deployment.

01
BlenderMCP + Melodia Studio: Connect the open Blender 5.2 GUI on port 9876 via N → BlenderMCP. LiveLink in-addon is a stub. GN Stack: 165 builders / 12 categories as of 2026-08-13.
02
Monolith MCP Orchestration: Execute Unreal automation over Port 9316 HTTP, logging to MonolithCalls.jsonl. Do not use legacy Port 9317 for Blender.
03
UEBlueprintMCP Socket API Injection: Query and inject length-prefixed Blueprint graph nodes dynamically via Port 55558 TCP.
04
Toon Profile Math & sRGB-to-Linear Transformation: Execute create_tp_melusina.py to configure TP_Melusina toon profile ramps and transform colors (e.g., `#352D40` → `LinearColor(0.035133, 0.026330, 0.052814, 1.0)`).
05
TouchDesigner CHOP Real-Time Audio Streaming: Run build_harmonic_audio_streamer.py to broadcast 4-band audio CHOPs (Sub-Bass, Mid-Range, High-Freq, Master RMS) driving Niagara VFX and bloom.
06
VOICEVOX & Melusina Dialogue Synthesis: Generate Japanese character voice audio and timing lip-sync metadata via REST Ports 50021 and 50022.
07
Web Asset Product Compilation & Packaging: Execute tools/build_asset_products.py to compile renders into 135 Twitch Emotes, 7 OBS Overlays, 78 Wallpapers, and 12 300dpi Postcards.
