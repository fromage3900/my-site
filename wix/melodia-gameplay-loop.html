WBP_MelodiaRhythmHighway & Timing Deferral Math

OWNER LOCK WORKED. Optional Harmonix rhythm layer. Formal runtime harness with real Q/W/O/P is still OPEN — this page is the look-book, not a PIE claim.

128 BPM Music Clock Resolution & Damage Multiplier Deferral

The rhythm engine integrates UMusicClockComponent loaded with the 128BPMarpeggiomelody_beatgrid beat map. When a player executes UseSkillWithRhythm(StockSkill), damage output is deferred until FinishSession() latches the PendingDamageMultiplier at the end of the note highway stream (~3.05s latch window). This prevents premature anim-notify resolution (which occurs at ~0.51s) from truncating player rhythm input.

Terminal State Resolution

Combat Result Matrix & C++ Post-Battle Restoration

Typed terminal result handling via EBSBattleResult and property reflection fixes in UMelodiaJRPGPostBattleLibrary.

Result Enum (EBSBattleResult) Bridge Delegate Behavior Narrative & Level Routing Post-Battle Party Restore
Victory Fires OnBattleOver(Victory) Idempotent XP/loot granted via UMelodiaGameStateSubsystem; resumes QuillScript victory branch. Executes UMelodiaJRPGPostBattleLibrary::RestorePartyAfterBattle (restores HP/MP, fixes currentMP reflection).
Defeat Fires OnBattleOver(Defeat) Triggers defeat dialogue or reloads last canonical checkpoint from Melodia_SaveSlot_0. Restores party to pre-battle state upon reload from disk.
Fled Fires OnBattleOver(Fled) Returns party to exploration state in L_KaleidoNave at pre-encounter vector without rewards. Retains current party HP/MP levels without post-battle bonus restore.
Unavailable Fires OnBattleOver(Unavailable) Triggers null-check fallback; reroutes narrative to safe anchor Morning_RoomShell. Bypasses reward processing and logs warning to telemetry log.
C++ Patch DetailProperty Reflection Fix

UMelodiaJRPGPostBattleLibrary & Property Reflection Fix

The static C++ library UMelodiaJRPGPostBattleLibrary executes party cleanup upon combat completion. During audit, a legacy reflection property typo was identified where character Magic Points were bound as curentMP. This has been updated to the canonical property currentMP across all Blueprint reflection tables, ensuring status restoration functions cleanly without silent property lookup failures.
