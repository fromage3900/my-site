Widget Components

Reusable UI Atoms

Five widget blueprints with cute elements and documented gameplay integration.

Menu Button

Reusable button with corner stars, hover sparkle, and 4 states (Default/Hover/Pressed/Disabled). Binds to SaveGame, OpeningFlow, Settings subsystems.

Sparkle FX

Shared sparkle effects: Burst (one-shot), Drift (ambient), Orbit (Comic Orrery). Density tiers (Full/Soft/Chrome/Off) from settings.

Keybind Badge

JRPG keybind visualizer: F (Interact), J (Attack), K (Skill), L (Ultimate), E (Menu), ESC (Back). Nikki color mapping with glow states.

Parchment Panel

Base panel with musical clef watermark, scroll edges, and paper grain. Background for SaveLoad, Settings, QuestJournal, NPCInfo.

Filigree Border

Baroque decorative borders: corners, edges, crest. Gold/500 color with optional header accent for MainMenu and important panels.

Implementation Pipeline

From Figma to UE5

Automated pipeline for design system synchronization and widget creation.

1. Token Parser

Python script parses Figma tokens.json, resolves references, outputs UE-compatible JSON with 170+ tokens.

2. Data Asset

UE5 script imports tokens to Dmocap animation data asset with Blueprint-callable getters.

3. Widget Scaffolds

Python generates widget scaffold JSON from Figma specs with gameplay integration notes.

4. Texture Generation

PIL script generates star sprites, filigree patterns, cursors, parchment grain textures.

5. Widget Creation

UE5 Python API creates widget blueprints from scaffolds with pre-built hierarchy.

6. Figma MCP

Figma MCP integration ready for pulling component specs and exporting assets directly.
