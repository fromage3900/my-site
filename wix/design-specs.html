The 12 P0 Foundation Verification Gates

Binary validation criteria governing the JRPG vertical slice architecture across input parity, combat transitions, narrative fallbacks, and standalone deployment packaging.

Gate # Gate Name Technical Specification & Behavior Verification Criteria
P0-01 Battle Widget Identification Instantiate tactical combat viewport interface at runtime on battle initialization at viewport z-order 10. Battle UI widget is visible and focusable upon combat start in PIE.
P0-02 Input Parity & Debouncing Enforce 150ms input debouncing in UMelodiaInputContextSubsystem across Mouse, Keyboard, and Gamepad for Attack, Skill, Item, Flee. Single keypress triggers exactly one combat action without duplicate triggers.
P0-03 Result Matrix Pass Bind OnBattleOver delegate in MelodiaExternalJRPGBridgeSubsystem to transition Victory, Defeat, Fled, Unavailable back to exploration. Each terminal combat result resumes or aborts Quill narrative interpreter exactly once.
P0-04 Save/Load Restart Persistence Serialize canonical game state slot using binary USaveGame architecture. Game state persists accurately across full application process restarts.
P0-05 Flag & Reward Restore Idempotency Enforce idempotent flag validation in UMelodiaGameStateSubsystem prior to granting items or XP upon level reload. Rewards and narrative flags do not duplicate upon level reload or save loading.
P0-06 Quill Unavailable Load Implement null-check fallback in QuillScriptInterpreter to bypass missing dialogue files and default to free exploration. Canonical JRPG slot loads cleanly when Quill assets are missing/unavailable.
P0-07 Safe Script Rerouting Route missing or corrupted dialogue script branches to the default safe sanctuary fallback anchor. Invalid narrative nodes recover safely without wiping current player progress.
P0-08 Interpreter Invalidation Handling Latch bIsTerminating flag during level transitions and flush pending script delegates while retaining pending results. Mid-dialogue level transition flushes cleanly without stale pointer crashes.
P0-09 Mid-Battle Save Disabling Enforce bCanSave = false in USaveGameSubsystem upon entering EBSBattleState::InBattle. Manual saving is disabled/hidden during active turn-based combat encounters.
P0-10 Main Menu Wiring Wire New Game, Continue, Load in WBP_MainMenu directly to UMelodiaTravelSubsystem and canonical BP_MelodiaJRPGGameInstance. Main Menu buttons route cleanly to gameplay levels and canonical save slots.
P0-11 Room Shell Validator Repair Verify spawn anchor component on morning sanctuary player start actor. Level validator confirms spawn anchor presence during initial load.
P0-12 Packaged Route Launch Include Morning Sanctuary, Dreamstate Traversal, and Kaleido Nave in standalone map cooking package. Executable launches and runs standalone outside Unreal Editor without black screens.
