Procedural PCG Library — Baroque

34 graphs. 9 verified. Recursive rooms.

The Baroque PCG library is shared between L_FallenMoon and KaleidoNave's cathedral approach. It provides colonnade scatter, garden tiers, ruined structures, and overgrown ivy dressing. FallenMoon uses the ruin and overgrowth graphs to dress procedurally-generated dungeon rooms.

Column rows — 48+ instances verified ✅ on L_FallenMoon. Pilaster and capital scatter along dungeon corridors.

Garden

PCG_TerraceGarden

Tiered garden scatter — 211+ instances verified ✅. Moss, low foliage, stone tiles. Appears in Room A blessing areas and exit passages.

Ruins

PCG_BaroqueRuins

Ruined baroque structures verified ✅. Collapsed arches and weathered block scatter at room boundaries and Room B encounter zones.

Overgrowth

PCG_OvergrownRuins

Overgrown ruin variant verified ✅. Ivy, vine cards, and moss creep over room geometry — key visual signal for deep dungeon progression.

Run Loop — Seeded Expedition

Room A → blessing/burden → Room B → exit.

FallenMoon's expedition loop is seeded and recorded — each run follows a deterministic path for reproducible playtesting. Room A presents a blessing/burden choice (social stat mechanic). Room B is an encounter. Exit closes the bar. The Persona layer (SocialStats/Harmony/Tempo/Timbre) is designed against this loop.

Room A

Blessing / Burden choice

Quill dialogue choice seeded to a stat gain. SocialStats (Harmony, Tempo, Timbre) modified by the choice. The stat gate drives gated content availability downstream.

Room B

Encounter — Rhythm Battle

Rhythm battle spawned via melodia_smoke_encounter pattern. DealDamage reads GetPendingDamageMultiplier(). Grade feedback PERFECT/GREAT/GOOD/MISS live.

Persona

Social Stats — Harmony/Tempo/Timbre

Stats named musically. PhaseIndex advances on bed rest. One dream = one movement = one bar. Schema supports repetition without needing a calendar system for the vertical slice.

Material Language — Fallen Moon

Weathered gothic. Baroque toon. SDF ornament.

FallenMoon's dungeon materials use the gothic/baroque material family: MI_Show_StoneCliff (weathered stone), MI_Trimsheet_HeavyWear (trimsheet wear pass), and MI_Zen_Karesansui for moss and floor infill. All run on M_Master_Toon_Universal with SDF ornamental detail in transition areas.

Material

MI_Show_StoneCliff

Weathered stone — large structural surfaces and colonnade columns. Substrate Toon BSDF, triplanar mapping for seamless application on PCG-scattered geometry.

Material

MI_Trimsheet_HeavyWear

Heavy-wear trimsheet — door arches, border details, transition zones. Parallax-offset wear on baroque stonework. Defined in ROLE_UE_HINTS for PGA integration.

Material

MI_Zen_Karesansui

Moss/floor infill — organic ground coverage, zen garden material variant. Used in Room A blessing areas and overgrown corridor sections.
