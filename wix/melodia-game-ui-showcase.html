Design Rationale

Why these choices.

Aesthetic Direction

Baroque · Romantic Fantasy

The Baroque filigree system draws from the same visual DNA as Genshin Impact's ornate menus and Infinity Nikki's fashion-fantasy UI — gold filigree, ink seals, parchment substrates. Original design; every vector authored from scratch in Figma.

Motion Design

19 Motion Channels

Timing and easing defined in the Figma RhythmReactivityBoard (node 41:242). A 2,400ms animation loop drives StaffShimmer, NoteTrailIri, and BreakCrestReveal — synced to both web CSS @keyframes and Unreal NativePaint driver fields.

Figma → UE5 Pipeline

Single Source of Truth

Assets exported from the Figma Grandmaster file (Yx8ud7n39NdWZvnNvo4Xlf) at 2× PNG. Web CSS binds to the same named tokens used in Unreal UMG Blueprints, maintaining design parity between web portfolio and runtime game UI.

Accessibility

Reduced Motion Support

All animations respect prefers-reduced-motion. The data-mg="off" attribute silences every motion cue for users who opt out. Grade states readable without animation.

Production Pipeline

Figma → UMG in four steps.

01

Design in Figma

Components authored as Figma primitives — EllipseNode arc fills, gradient parchment, vector grain hatching, clef glyph watermarks.

›
02

Export via Plugin

Figma Plugin API batch-exports all slots at 2× PNG. ART_SOURCE.json records component node IDs, kit names, and binding contracts.

›
03

Web Deployment

PNGs referenced in melodia-game-ui.css via data-mg selectors. Motion channels from melodia-motion-connect.json drive CSS @keyframes.

›
04

UMG Runtime

Same PNGs imported into Unreal Engine UMG Blueprints. NativePaint driver reads motion spec from _MOTION_CHANNELS.md maintaining web/runtime parity.
