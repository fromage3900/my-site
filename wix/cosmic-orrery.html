Environment — Sakura Dream

Sakura blossom. Toon canopy. PCG scatter.

The Zen Forest environment hosts the Universal PCG library — PCG_SakuraGrove (tree density falloff), PCG_Zen_MossGroundcover (biome blend + slope exclusion), PCG_Sakura_PetalDrift (Niagara petal system with Nanite sakura petal mesh), and PCG_BlossomPath along the combat route. Substrate Toon canopy materials share M_Master_Toon_Universal.

Scatter

PCG_SakuraGrove

Sakura tree scattering with density falloff around the combat clearing. Verified ✅ in ZenForestTest. Universal PCG library.

Ground

PCG_Zen_MossGroundcover

Moss and groundcover with biome blending and slope exclusion. Fills the forest floor around encounter zones.

VFX

PCG_Sakura_PetalDrift

Petal drift along the combat route — animated Niagara petal system with real Nanite sakura petal mesh. Runs during rhythm sessions.

Path

PCG_BlossomPath

Blossom scatter along the player approach route — Universal PCG library, density-falloff variant. Guides the player toward combat zones.

Rhythm Combat — Live in this level

4 lanes. 192 notes. No fails.

The full rhythm combat system runs in ZenForestTest: 4-lane highway (D/F/J/K), 192-note MIDI chart at 128 BPM parsed from real MIDI, PERFECT/GREAT/GOOD/MISS grade feedback via SetJudgment, WBP_MelodiaRhythmHighway at z90 under both UI authorities. Damage scaling: both DealDamage sites read GetPendingDamageMultiplier().

Highway

WBP_MelodiaRhythmHighway

Created → viewport(z90) → cast → stored → BindRhythmHUD → shown in BP_BattleUI. Removed + InvalidateSession on hide. z90 sits under both UI authorities.

Damage

DamageMultiplier — Live

Both DealDamage call sites read GetPendingDamageMultiplier(). UMelodiaPersonaSubsystem::HandleRewardRequested + RewardEquipment map (3 entries seeded). Damage scaling is real, not placeholder.

Grade

PERFECT / GREAT / GOOD / MISS

RegisterLaneHit calls SetJudgment(GradeToText(Grade)) on BoundHUD for every lane press. BP_DamageTextUI candidate for crit/grade-coloured damage numbers. Feedback live.
