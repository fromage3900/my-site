Bulk Skinning Pipeline

Convert all 18 remaining stock widgets to Melodia in a single pass using find/replace across the T3D exports, then re-inject via build_blueprint_from_spec.

Step 1: Find/Replace Texture Paths

Run this PowerShell command to batch-replace stock texture references with Melodia equivalents across all T3D files:

$dir = "C:\EnvironmentPortfolio\BS_GodFile\Saved\T3D\full_catalog"
$replacements = @{
  "Texture2D '/Game/TurnBasedJRPGTemplate/Textures/UI/T_ActionBarBG'" = "Texture2D '/Game/MelodiaCore/Textures/UI/T_Melodia_Universal_ParchmentFrame'"
  "Texture2D '/Game/TurnBasedJRPGTemplate/Textures/UI/T_DamageNumber'" = "Texture2D '/Game/MelodiaCore/Textures/UI/T_Melodia_Universal_FiligreeNumber'"
  "Texture2D '/Game/TurnBasedJRPGTemplate/Textures/UI/T_HPFill'"      = "Texture2D '/Game/MelodiaCore/Textures/UI/T_Melodia_Universal_GildedFill'"
  "Texture2D '/Game/TurnBasedJRPGTemplate/Textures/UI/T_MPFill'"      = "Texture2D '/Game/MelodiaCore/Textures/UI/T_Melodia_Universal_CrystalFill'"
  "Texture2D '/Game/TurnBasedJRPGTemplate/Textures/UI/T_PortraitFrame'" = "Texture2D '/Game/MelodiaCore/Textures/UI/T_Melodia_Universal_CameoFrame'"
  "Texture2D '/Game/TurnBasedJRPGTemplate/Textures/UI/T_TargetRing'"  = "Texture2D '/Game/MelodiaCore/Textures/UI/T_Melodia_Universal_OrnateRing'"
  "Texture2D '/Game/TurnBasedJRPGTemplate/Textures/UI/T_DialogueBG'"  = "Texture2D '/Game/MelodiaCore/Textures/UI/T_Melodia_Universal_ParchmentFrame'"
  "Texture2D '/Game/TurnBasedJRPGTemplate/Textures/UI/T_ItemIcon'"    = "Texture2D '/Game/MelodiaCore/Textures/UI/T_Melodia_Universal_ItemGlyph'"
  "Texture2D '/Game/TurnBasedJRPGTemplate/Textures/UI/T_EquipmentSlot'" = "Texture2D '/Game/MelodiaCore/Textures/UI/T_Melodia_Universal_EquipmentBorder'"
  "Texture2D '/Game/TurnBasedJRPGTemplate/Textures/UI/T_PartyPortrait'" = "Texture2D '/Game/MelodiaCore/Textures/UI/T_Melodia_Universal_PortraitCrest'"
  "Texture2D '/Game/TurnBasedJRPGTemplate/Textures/UI/T_MenuBG'"      = "Texture2D '/Game/MelodiaCore/Textures/UI/T_Melodia_Universal_VelvetBackdrop'"
}
Get-ChildItem $dir -Filter *.t3d | % {
  $c = Get-Content $_.FullName -Raw
  $replacements.Keys | % { $c = $c -replace [regex]::Escape($_), $replacements[$_] }
  $c | Set-Content $_.FullName -Encoding utf8
}
Write-Output "Bulk texture replacement complete on $((Get-ChildItem $dir -Filter *.t3d).Count) files"

Step 2: Re-inject via Monolith MCP

For each modified T3D, call build_blueprint_from_spec to re-inject the Melodia-skinned graph:

$body = @{
  jsonrpc = "2.0"; id = 1; method = "tools/call"
  params = @{
    name = "blueprint"
    arguments = @{
      action = "build_blueprint_from_spec"
      bp_path = "/Game/TurnBasedJRPGTemplate/Blueprints/UI/BP_ActionTimeBar"
      spec_path = "C:\EnvironmentPortfolio\BS_GodFile\Saved\T3D\full_catalog\BP_ActionTimeBar.t3d"
      auto_compile = $true
    }
  }
} | ConvertTo-Json -Depth 10
Invoke-RestMethod -Uri "http://127.0.0.1:9316/mcp" -Method Post -Body $body -ContentType "application/json" -TimeoutSec 60

Step 3: Batch Injection (all 18 in parallel)

Use ThreadPoolExecutor to re-inject all 18 widgets in ~2 minutes:

python -c "
import json, urllib.request, os
widgets = [f.replace('.t3d','') for f in os.listdir('C:/EnvironmentPortfolio/BS_GodFile/Saved/T3D/full_catalog') if f.endswith('.t3d')]
from concurrent.futures import ThreadPoolExecutor
def inject(w):
  body = json.dumps({'jsonrpc':'2.0','id':1,'method':'tools/call','params':{'name':'blueprint','arguments':{'action':'build_blueprint_from_spec','bp_path':'/Game/TurnBasedJRPGTemplate/Blueprints/UI/'+w,'spec_path':'C:/EnvironmentPortfolio/BS_GodFile/Saved/T3D/full_catalog/'+w+'.t3d','auto_compile':True}}}).encode()
  r = urllib.request.Request('http://127.0.0.1:9316/mcp', data=body, headers={'Content-Type':'application/json'})
  return w, urllib.request.urlopen(r, timeout=60).status
with ThreadPoolExecutor(max_workers=4) as ex:
  for w, s in ex.map(lambda w: inject(w), widgets):
    print(f'{w}: {\"OK\" if s==200 else \"FAIL\"} ({s})')
"
